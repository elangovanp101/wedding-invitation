# Wedding Invitation Project

This project is a custom, production-quality, mobile-first wedding invitation website for Elangovan and Selvaveena. The website aims to provide a luxurious and cinematic experience, combining traditional Tamil aesthetics with modern web technologies.

## Project Structure

The project is organized into the following main directories:

- **components/**: Contains reusable React components for different sections of the wedding invitation.
- **data/**: Holds data files for wedding information and translations.
- **pages/**: Contains the Next.js pages for the application.
- **public/**: Stores static assets such as images, audio, and fonts.
- **styles/**: Includes global styles for the application.
- **.env.local**: Configuration for environment variables.
- **.gitignore**: Specifies files to be ignored by Git.
- **next.config.js**: Configuration settings for the Next.js application.
- **package.json**: Lists project dependencies and scripts.
- **tsconfig.json**: TypeScript configuration settings.

## Technologies Used

- **React**: For building user interfaces.
- **Next.js**: For server-side rendering and routing.
- **TypeScript**: For type safety and improved developer experience.
- **Tailwind CSS**: For styling and responsive design.
- **Framer Motion**: For animations and transitions.

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone <repository-url>
   cd wedding-invitation
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run the Development Server**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000` to view the application.

## Usage

- The website features an elegant opening experience with animated names and a cinematic introduction.
- Users can switch between English and Tamil languages seamlessly.
- The music controller allows guests to enjoy background music while navigating through the invitation.
- Guests can leave wishes and RSVP for the wedding events.
